# Compatibility adapter

The canonical, tool-agnostic workflow is [agentic/skills/aidd-feature](../../../agentic/skills/aidd-feature/SKILL.md). Read and follow it first.

This file exists so Codex discovers the workflow automatically. It is not an independent authority. The canonical domain rules are in [agentic/skills/live-console-domain](../../../agentic/skills/live-console-domain/SKILL.md), permanent restrictions are in [agentic/rules/live-console-v1.md](../../../agentic/rules/live-console-v1.md), and the current foundation plan is in [agentic/specs/v1-foundation](../../../agentic/specs/v1-foundation/README.md).

When a tool-specific convention conflicts with `agentic/`, the approved project spec and the latest explicit decision by Denner prevail.
